# Шрифты Jester Jack

Интерфейс использует **Source Sans 3** для основного текста и кнопок, а **Cormorant Garamond** сохраняет классический вид крупных заголовков. Обе гарнитуры включены в `assets/` с лицензиями; системные шрифты Windows не требуются.

## Cormorant Garamond

`CormorantGaramond-Regular.ttf` и `CormorantGaramond-SemiBold.ttf` - классическая гарнитура Cormorant Garamond без пиксельной стилизации. Статические TrueType-файлы подходят для встроенного растеризатора Dear ImGui.

Автор: Christian Thalmann и участники Cormorant Project. Лицензия: **SIL Open Font License 1.1**; полный текст сохранён в [OFL-CormorantGaramond.txt](OFL-CormorantGaramond.txt).
