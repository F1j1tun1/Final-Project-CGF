# Проверка перед передачей

Дата: 15 октября 2026. Это результаты стартового прототипа.

## Окружение

- Windows x64, SDK 10.0.26100.0.
- Visual Studio 18 2026; MSVC 19.51.36260.0; CMake 4.4.3.
- Intel RaptorLake-S Mobile Graphics Controller.
- OpenGL `3.3.0 - Build 32.0.101.7026`, core profile.
- Окно и сохранённые кадры: 1440 × 900.

## Выполненные проверки

1. Конфигурация `cmake --preset desktop` и сборка приложения/тестов Debug, затем Release. Последняя сборка Release завершилась без предупреждений собственного кода.
2. `ctest --test-dir build/desktop -C Release --output-on-failure -V`: 1 тестовый исполняемый файл, 3 000 seeded-забегов, 1 147 808 проверок, 0 ошибок. Проверки включают тузы, натуральный блэкджек, исходы, работу дилера, все улучшения, магазин, недопустимые команды и оба финала. В тестовой стратегии 245 забегов завершились победой, 2 755 — поражением; это данные покрытия, а не итоговая оценка баланса.
3. `blackjack_forge.exe --hidden --demo --frames 3 --screenshot preview.png`: окно/контекст, загрузка и компиляция шейдеров, меши, текстуры и UI работают на указанном драйвере.
4. `blackjack_forge.exe --smoke --frames 600`: 600 кадров без ошибок OpenGL; seed 42 проходит два магазина и достигает победы на третьем этапе около кадра 400, после чего начинается новый забег.
5. Отдельные кадры экрана игры, магазина и победы проверены визуально. Исправлены наложение плоскости текстуры на объём карты и размещение кнопок магазина.
6. `core-only` отдельно сконфигурирован, собран в Debug и проверен CTest без графических библиотек: тест правил прошёл.
7. Установленная Release-папка запускается из другого рабочего каталога и загружает шейдеры рядом с executable; PNG-кадр сохранён успешно.

MSBuild с несколькими worker nodes зависал внутри среды исполнения Codex. Сборка завершилась при `--parallel 1 -- /nr:false` вне ограничения sandbox; ошибки C++ или OpenGL причиной этого зависания не были. Обычная команда сборки сохранена в README, скрипт Windows использует один процесс.

## Остаётся проверить

- Чистую сборку и запуск на машине TA; macOS и ручной запуск Linux на другой видеокарте (проверка Linux в CI указана ниже).
- Полное ручное прохождение мышью/клавиатурой, изменение размеров окна, DPI и другое оборудование. Автоматический прогон вызывает игровые команды; он не имитирует все клики по кнопкам.
- Настройку целей и наград с командой, удобство текста, читаемость всех комбинаций карт.
- Будущую анимацию раздачи/переворота и звук после их реализации.

Для сдачи требуются также официальный отчёт, демо 3–6 минут и слайды; эти материалы здесь не объявляются готовыми.
