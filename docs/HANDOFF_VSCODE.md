Изменения делайте в отдельной ветке и PR, согласовав общие файлы.

## Текущее поведение

- Название **Jester Jack**. В меню увеличенный заголовок вверху слева, ниже слева три большие вертикальные кнопки START, OPTIONS, EXIT разных цветов. Справа увеличенное казино в три четверти вдоль дороги, при вечернем закатном освещении. Палитра фиолетовая, золотая, красная; английский UI использует Cormorant Garamond для заголовка и читаемый Source Sans 3 для основного текста/кнопок.
- START запускает затемнение/проявление за 0,9 секунды и новый забег у стола в фазе `Ready`. Раздача начинается отдельной командой. В переходе ввод заблокирован, повторный старт не создаёт вторую игру.
- Казино и интерьер создаются процедурно. Видимого персонажа дилера за столом нет, карты дилера сохраняются. Настройки камеры, освещения, текстур и фонового движения сохранены, стартовый переход можно выключить.
- HUD: большая цель/очки и счётчики раздач/монет слева; увеличенный ряд из четырёх карточек активных улучшений с яркими бейджами редкости сверху; стол в центре справа и действия внизу справа. В магазине баланс показан крупным числом с иконкой монет. Полные правила открываются через HOW TO PLAY. Ориентир компоновки - [официальные изображения Balatro](https://store.steampowered.com/app/2379780/Balatro/); его ресурсы в игру не включены.
- **Раздача** - одна рука против дилера; **раунд** - до пяти раздач с целью по очкам. Раунды бесконечны, без ставок и финальной победы. Цели: 30, 40, 50, 60, 70, 80, 90, 100, затем всегда 100. Дилер останавливается на 17.
- Проигрыш руки даёт ноль и обрывает серию; ничья даёт ноль, сохраняя серию. После всех пяти раздач без цели автоматически появляется GAME OVER с RETRY, MAIN MENU, QUIT GAME. Проверка выполненной цели имеет приоритет: последняя успешная раздача позволяет перейти в магазин.
- Каждая победная рука приносит 3 монеты и бонусы активных улучшений. Очки идут к цели раунда и в общий результат забега. Магазин открывается только после выполнения цели: два стабильных случайных предложения из 12 улучшений. После магазина следующий раунд получает пять раздач и нулевой счёт раунда.
- Максимум 4 активных улучшения, без дубликатов. Цены 2/4/6/8/10; продажа в магазине за половину цены. Проданное может появиться позже. Редкости Common/Uncommon/Rare/Epic/Legendary имеют базовые веса 50/28/14/6/2; сначала выбирается доступная редкость, затем предмет внутри неё. Предпочтение новым предложениям работает внутри редкости, пустые редкости исключаются с пересчётом весов. Покупки/продажи не обновляют пару. Second Chance действует один раз за раунд, обновляется между раундами, а не при продаже. Каталог, усиленные Rare/Epic эффекты и точные вычисления - в архитектуре.
- Каждая раздача использует новую равномерно перемешанную колоду 52 карт. Обычный запуск получает новый случайный seed; `--seed N` воспроизводит забег при одинаковых действиях. RNG карт и магазина разделены; у `--smoke` seed по умолчанию 42.

Событийная анимация раздачи/переворота карт и звук пока не реализованы. Кастомные звуки и саундтреки - будущие материалы команды. Стартовое затемнение не означает готовность анимаций карт.

## Сборка и запуск

Установите CMake 3.24+ и компилятор C++17 по README. На Windows нужны MSVC и Windows SDK из Visual Studio/Build Tools; редактор их не заменяет. В VS Code можно использовать Microsoft C/C++ и CMake Tools, preset `desktop`, target `blackjack_forge`. Название executable сохранено для совместимости.

```text
cmake --preset core-only
cmake --build --preset core-only --parallel
ctest --preset core-only
cmake --preset desktop
cmake --build --preset desktop --parallel
ctest --preset desktop
```

Для Visual Studio на Windows:

```powershell
# Обычный запуск с главным меню.
.\build\desktop\Debug\blackjack_forge.exe

# Воспроизводимая раздача, минуя меню.
.\build\desktop\Debug\blackjack_forge.exe --demo --seed 42

# Графическая интеграция и кадры встреченных состояний.
.\build\desktop\Debug\blackjack_forge.exe --smoke --frames 600 --capture-states build/captures
```

Для Ninja/Linux путь отличается; системные пакеты описаны в README. `core-only` не требует окна и GPU, но не проверяет графику. Для smoke и скрытых снимков нужен рабочий OpenGL-контекст. Сборка копирует `assets/` рядом с executable, включая шрифты и лицензию; переносите эту папку вместе с программой. `--assets DIR` позволяет явно задать корень ресурсов.

Space выполняет основное действие текущей фазы: START, раздать, Stand в `PlayerTurn`, продолжить результат, следующий раунд в магазине, RETRY на GAME OVER. Enter активирует выделенную кнопку UI. F1 открывает настройки; Escape закрывает их либо возвращает в меню; EXIT/QUIT GAME завершает приложение. START и RETRY начинают новый забег. При фиксированном seed RETRY увеличивает его на 1; для точного повтора запустите программу снова с нужным `--seed`.

## Контракт модулей

| Файлы | Ответственность |
| --- | --- |
| `src/game/Game.hpp`, `Game.cpp` | Чистые правила, Snapshot, deterministic RNG, команды `deal/hit/stand/advance/buy/sell/leaveShop/restart` |
| `src/graphics/Renderer.hpp`, `Renderer.cpp` | Scene, нормированный tableViewport, меши, камера, материалы, свет, текстуры, меню/стол и GPU RAII |
| `src/main.cpp` | GLFW, ImGui, настройки, команды, стартовый переход и Snapshot -> Scene |
| `assets/shaders/` | GLSL 330: model/view/projection, нормали, UV, Blinn-Phong |
| `assets/fonts/` | Cormorant Garamond и Source Sans 3, OFL и происхождение |
| `tests/game_tests.cpp` | Правила, guards, награды, магазин и воспроизводимость |

В `Game` нельзя добавлять время, визуальные координаты, файловый ввод/вывод или зависимости GLFW/OpenGL/ImGui. Недопустимая команда возвращает `false`, ничего не меняя. Рендерер не выбирает карты и не начисляет монеты. Сохраняйте современный shader-based pipeline и уничтожайте GPU-ресурсы при живом контексте. Игра должна оставаться одинаковой при включённых и выключенных визуальных эффектах.

`gfx::Viewport {left, top, width, height}` задаёт нормированную область framebuffer от верхнего левого угла. `src/main.cpp` рассчитывает `Scene::tableViewport` под HUD; рендерер переводит область в OpenGL-координаты и её отношение сторон. При изменении компоновки обновляйте область стола вместе с UI, не добавляя координаты в `Game`.

## Проверка и продолжение

Фактические результаты находятся в [VERIFICATION.md](VERIFICATION.md). Исторические записи прежних версий не подтверждают новую корректировку правил и меню. Для новых изменений фиксируйте конкретные команды, окружение и результат; проверяйте меню, стартовый переход, стол, пять раздач на цель, магазин, продажу, проигрыш раунда, настройки и изменение размера окна. Отдельно остаются чистая сборка на другой машине и машина TA.

Выбирайте следующую задачу по текущему запросу команды, а не автоматически по старому запросу из чата. План - [ROADMAP.md](ROADMAP.md). Для анимаций карт нужны события презентации и стабильные ID вне игрового состояния; для будущего аудио - разрешённые материалы, лицензии и независимость правил от звука. Для баланса измеряйте статистику по seed и стратегиям. Условия сдачи - [COURSE_REQUIREMENTS.md](COURSE_REQUIREMENTS.md), учебные источники - [LECTURE_ALIGNMENT.md](LECTURE_ALIGNMENT.md).
