# Проверка Jester Jack

Дата новой проверки: **16 октября 2026**. Этот раздел относится к новой механике и оформлению Jester Jack; ниже отдельно сохранён архив стартового прототипа.

Окружение: Windows x64, Visual Studio 18 2026, MSVC 19.51, Windows SDK 10.0.26100.0, Intel RaptorLake-S Mobile Graphics Controller, OpenGL `3.3.0 - Build 32.0.101.7026`.

Выполнено:

1. `cmake --preset core-only`, `cmake --build --preset core-only --parallel`, `ctest --preset core-only` — успешны, Debug. Повторены после интеграции. MSVC запускался с доступом вне ограниченного sandbox; изменений генератора не понадобилось. Для собственного C++ явно включён `/EHsc`.
2. `cmake --preset desktop`, `cmake --build --preset desktop --parallel`, `ctest --preset desktop` — успешны, Debug. Собственный код собрался без предупреждений. После исправления компоновки повторена затронутая сборка и графическая проверка.
3. Тесты: **1 051 950 проверок, 0 ошибок**. Проверены 3 000 seeded-сценариев, тузы/исходы, все условия наград и Second Chance, продолжение после пяти раундов, первое поражение, стабильные два предложения, покупки только из предложения, четыре активных улучшения, продажа за полцены, повторное предложение проданного, запрет немедленной перепокупки, независимость RNG и неизменность состояния/будущей случайности при заблокированных командах.
4. На **40 000 начальных раздачах** натуральный блэкджек игрока встретился 1 867 раз (**4,668%**), дилера — 1 924 (**4,810%**). Теоретическая вероятность обычной руки — `2 * 4 * 16 / (52 * 51)`, около 4,83%. Вероятности не подменяются: разнообразие обычного запуска обеспечивается новым seed. Поисковые стратегии в тестах выбирают допустимые пути для покрытия; их число побед не является оценкой реального баланса.
5. `blackjack_forge.exe --smoke --frames 600 --capture-states build/verification/reviewed` — **600 кадров без ошибок OpenGL**. F1 открывает/закрывает настройки через события ImGui; START нажимается синтетическим событием мыши. Переход затемняется, переключает сцену и приводит к пустому столу `Ready`; далее автоматические команды проходят магазин, покупки, проигрыш и restart. В seed 42 достигнут пятый раунд, проигрыш завершает забег. Размер окна меняется 1440×900 → 1100×720 → 1440×900.
6. `--smoke --no-animation --frames 180` — успешен. Отключение перехода сохраняет ту же последовательность рук и наград при тех же действиях, меняется только время показа. `--smoke --frames 136 --screenshot build/verification/narrow-shop.png` дополнительно подтвердил компоновку магазина 1100×720.
7. Визуально просмотрены меню, настройки со всеми нижними кнопками, игровой стол, две карточки магазина и финал; также три кадра стартового затемнения и магазин на минимальном размере. Исправлены перекрытие магазина игровыми панелями, обрезание настроек и верхушки колпака. Сохранённые примеры: [меню](images/jester-menu.png), [стол](images/jester-table.png), [магазин](images/jester-shop.png). Промежуточные снимки находятся в игнорируемой папке `build/verification/`.
8. Запуск `blackjack_forge.exe` по имени через PATH из `build/verification/launch-cwd/` — успешен, кадр сохранён. Шейдеры и шрифты найдены в `assets/` рядом с executable; запуск не требует корня репозитория.

Не проверены в этой сессии: новая версия на Linux/macOS, другой GPU, машина TA и полный ручной игровой прогон. Smoke использует реальные события ImGui для настроек/START, но последующие действия вызывает через API игры; он не подтверждает каждый пользовательский клик и баланс. Звук и событийные анимации карт пока не реализованы. Удалённый CI старого прототипа ниже не считается проверкой Jester Jack.

## Выполненные проверки

1. Конфигурация `cmake --preset desktop` и сборка приложения/тестов Debug, затем Release. Последняя сборка Release завершилась без предупреждений собственного кода.
2. `ctest --test-dir build/desktop -C Release --output-on-failure -V`: 1 тестовый исполняемый файл, 3 000 seeded-забегов, 1 147 808 проверок, 0 ошибок. Проверки включают тузы, натуральный блэкджек, исходы, работу дилера, все улучшения, магазин, недопустимые команды и оба финала. В тестовой стратегии 245 забегов завершились победой, 2 755 — поражением; это данные покрытия, а не итоговая оценка баланса.
3. `blackjack_forge.exe --hidden --demo --frames 3 --screenshot preview.png`: окно/контекст, загрузка и компиляция шейдеров, меши, текстуры и UI работают на указанном драйвере.
4. `blackjack_forge.exe --smoke --frames 600`: 600 кадров без ошибок OpenGL; seed 42 проходит два магазина и достигает победы на третьем этапе около кадра 400, после чего начинается новый забег.
5. Отдельные кадры экрана игры, магазина и победы проверены визуально. Исправлены наложение плоскости текстуры на объём карты и размещение кнопок магазина.
6. `core-only` отдельно сконфигурирован, собран в Debug и проверен CTest без графических библиотек: тест правил прошёл.
7. Установленная Release-папка запускается из другого рабочего каталога и загружает шейдеры рядом с executable; PNG-кадр сохранён успешно.

MSBuild с несколькими worker nodes зависал внутри среды исполнения Codex. Сборка завершилась при `--parallel 1 -- /nr:false` вне ограничения sandbox; ошибки C++ или OpenGL причиной этого зависания не были. Обычная команда сборки сохранена в README, скрипт Windows использует один процесс.

## Остаётся проверить

- Чистую сборку и запуск на машине TA; macOS и ручной запуск Linux на другой видеокарте (проверка Linux в CI указана ниже).

- Настройку целей и наград с командой, удобство текста, читаемость всех комбинаций карт.
- Будущую анимацию раздачи/переворота и звук после их реализации.

Для сдачи требуются также официальный отчёт, демо 3–6 минут и слайды; эти материалы здесь не объявляются готовыми.
