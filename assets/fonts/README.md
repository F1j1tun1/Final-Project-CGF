# Jester Jack fonts

The interface uses **Source Sans 3** for body text and buttons, while **Cormorant Garamond** gives large headings a classic look. Both font families and their licenses are included in `assets/`; Windows system fonts are not required.

## Cormorant Garamond

`CormorantGaramond-Regular.ttf` and `CormorantGaramond-SemiBold.ttf` are static Cormorant Garamond TrueType fonts without pixel styling. They are suitable for Dear ImGui's built-in rasterizer.

Author: Christian Thalmann and the Cormorant Project contributors. License: **SIL Open Font License 1.1**; the complete license is preserved in [OFL-CormorantGaramond.txt](OFL-CormorantGaramond.txt).

Source: the official [google-fonts-bower/cormorantgaramond-bower](https://github.com/google-fonts-bower/cormorantgaramond-bower) repository, commit `bcf5515652e4d99eb3e42e41ed5f4285a315a175`. Retrieved on October 16, 2026, without modifying the files.

## Source Sans 3

`SourceSans3-Regular.ttf` and `SourceSans3-Semibold.ttf` are static TrueType files for a readable sans-serif family. Body text uses Regular; buttons and labels use Semibold. The files were retrieved without modification on October 16, 2026 from the official [adobe-fonts/source-sans](https://github.com/adobe-fonts/source-sans) repository, branch `release`, commit `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e`.
